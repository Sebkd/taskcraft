## 1. Предложение

### Цель изменения

`PgStoreError::Database(sqlx::Error)` и `KafkaSourceError::Client(KafkaError)` выставляют типы драйверов в публичном API: мажорное обновление `sqlx` или `rdkafka` — несовместимость наших пакетов.

### Инициатор

Код-ревью 0.3.0, бэклог код-ревью 0.3.0 (`docs/taskcraft-backlog_code-review-0.3.0.md`, локальный): BL-45.

### Затронутые компоненты

- [x] Пакеты `taskcraft-postgres`, `taskcraft-kafka`: типы ошибок

### Приоритет

низкий

### Обратная совместимость

Нет: несовместимое изменение типов ошибок.

### Объём реализации

Выпуск: 0.4.

**Реализует:**

- Свои варианты ошибок без типов драйвера в сигнатуре; исходная ошибка — через `source()`.
- Раздел в `MIGRATION.md`.

**Не входит:**

- Изменение поведения при ошибках.

**Зависит от заявок:** нет.
