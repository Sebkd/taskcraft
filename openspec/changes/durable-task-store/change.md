## 1. Предложение

### Цель изменения

Дать возможность сборки, при которой библиотека сама хранит задачи вне процесса: постановка, статус и история, отложенный повтор, восстановление без хуков потребителя. Это источник очереди; первая реализация — PostgreSQL.

Поверх хранилища — аренда и heartbeat: задачу может взять любой процесс, а при падении процесса её подхватывает другой по истечении аренды. Без аренды процесс со стабильным идентификатором при рестарте возвращает в очередь только свои прежние задачи.

### Инициатор

Разработка первой версии taskcraft (ветка `taskcraft/sebkd-1`). Требования первого потребителя — спецификация, раздел 1.1.

**Реализует:**

**Не входит:**

**Зависит от заявок:** `task-registry`, `ownership-and-recovery`

## 16. Рекомендации к критериям приёмки

Обязательны критерии спецификации №30, №31, №43, №44, №45 (раздел 3) — в той части, которую закрывает эта заявка. Дополнительно:

| # | КОГДА | ТОГДА |
|---|-------|-------|
| 1 | Два процесса одновременно опрашивают хранилище с одной задачей | Задачу получает ровно один |
| 2 | Постановка задачи с идентификатором завершённой задачи до истечения срока хранения | «Уже завершена» |
| 3 | Истёк срок хранения терминальной задачи | Запись удалена; постановка с тем же идентификатором создаёт новую задачу |
| 4 | Отмена задачи, которую выполняет другой процесс | Запрос записан, владелец отменяет задачу при следующем продлении аренды или опросе |
