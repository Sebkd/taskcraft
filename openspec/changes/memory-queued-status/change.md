## 1. Предложение

### Цель изменения

`fetch_status` для задачи, которая лежит в in-memory источнике и ещё не выдана опросом, отвечает «неизвестна», хотя источник её знает.

### Инициатор

Код-ревью 0.3.0, бэклог код-ревью 0.3.0 (`docs/taskcraft-backlog_code-review-0.3.0.md`, локальный): BL-42.

### Затронутые компоненты

- [x] Ядро `taskcraft`: `InMemorySource`, обёртка `Pushed`

### Приоритет

низкий

### Обратная совместимость

Да.

### Объём реализации

Выпуск: 0.3.x.

**Реализует:**

- `PushSource` получает необязательный метод статуса (по умолчанию «неизвестна»); in-memory источник отвечает «В очереди» с моментом доставки для отложенных.
- Тест: статус готовой и отложенной задачи.

**Не входит:**

- История завершённых задач в памяти.

**Зависит от заявок:** нет.
