## 1. Предложение

### Цель изменения

`Queue::on_store(name, store, handler)` без последующего `register` не выводит тип аргументов: компилятор просит аннотацию. Сервис уже знает тип — связь можно задать в сигнатуре.

### Инициатор

Код-ревью 0.3.0, бэклог код-ревью 0.3.0 (`docs/taskcraft-backlog_code-review-0.3.0.md`, локальный): BL-49.

### Затронутые компоненты

- [x] Ядро `taskcraft`: `Queue::on_store`

### Приоритет

низкий

### Обратная совместимость

Да (уточнение границы, если `semver-checks` не возразит; иначе — в 0.4).

### Объём реализации

Выпуск: 0.3.x.

**Реализует:**

- Граница `Svc: Service<TaskRequest<Args>>` в `on_store` (и при необходимости в `builder`, `consumer`).
- Doc-тест: `on_store` без аннотаций.

**Не входит:**

- Изменение остальных конструкторов сверх границы.

**Зависит от заявок:** нет.
