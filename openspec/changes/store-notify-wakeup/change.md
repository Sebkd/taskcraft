## 1. Предложение

### Цель изменения

Постановку из другого процесса воркер видит только при следующем опросе по стратегии. По умолчанию пауза растёт до 30 с; в примерах приходилось ставить интервал 200 мс. Итог — либо задержка до 30 с, либо лишняя нагрузка на базу.

### Инициатор

Код-ревью 0.1.0, бэклог код-ревью 0.1.0 (`docs/taskcraft-backlog_code-review-0.1.0.md`, локальный): BL-14.

### Затронутые компоненты

- [x] Пакет `taskcraft-postgres`

### Приоритет

средний

### Обратная совместимость

Да: стратегия опроса остаётся страховкой.

### Объём реализации

Выпуск: 0.2.

**Реализует:**

- `NOTIFY taskcraft_tasks, '<queue>'` при постановке, отложенном повторе и возврате задач.
- `LISTEN` в хранилище: уведомление будит `WakeSignal` воркеров своей очереди.
- Отключаемо настройкой — для пулеров соединений без поддержки `LISTEN`.

**Не входит:**

- Пробуждение по наступлению момента отложенной доставки — по-прежнему опросом.

**Зависит от заявок:** `store-schema-and-indexes`.
