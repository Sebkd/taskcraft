## 1. Предложение

### Цель изменения

`worker.rs` — 1,3 тыс. строк: цикл приёма, исполнение задачи, дренаж, уведомления источника, учёт пулов и журнал в одном модуле. `run_worker` — около 400 строк, `execute` — около 250. Ревью и правки дорожают: ошибки BL-01 и BL-02 лежали рядом и в одной функции.

### Инициатор

Код-ревью 0.1.0, бэклог код-ревью 0.1.0 (`docs/taskcraft-backlog_code-review-0.1.0.md`, локальный): BL-09.

### Затронутые компоненты

- [x] Ядро `taskcraft`: модуль `worker`

### Приоритет

низкий

### Обратная совместимость

Да: внутренняя переделка, поведение и публичный API не меняются.

### Объём реализации

Выпуск: 0.2.

**Реализует:**

- Модули `worker/{intake,execute,drain,notices,pools}.rs`; общие типы — в `worker/mod.rs`.
- Функции короче 100 строк, кроме тех, где это ухудшает чтение.

**Не входит:**

- Изменения поведения.

**Зависит от заявок:** `shutdown-drain-fixes` (сначала исправить, затем переносить).
