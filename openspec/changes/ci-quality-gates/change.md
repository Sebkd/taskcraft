## 1. Предложение

### Цель изменения

Четыре пробела в проверках перед выпусками.

1. Покрытие кода не измеряется.
2. Несовместимое изменение API может незаметно уйти в патч-версию.
3. CI только на Ubuntu, а разработка — на macOS: сборка `rdkafka` и пути инструментов различаются.
4. Job MSRV делает только `check`, тесты на Rust 1.99 не запускаются.

### Инициатор

Код-ревью 0.1.0, бэклог код-ревью 0.1.0 (`docs/taskcraft-backlog_code-review-0.1.0.md`, локальный): BL-21, BL-25, BL-32.

### Затронутые компоненты

- [x] CI (`.github/workflows`)

### Приоритет

средний

### Обратная совместимость

Да: поведение библиотеки не меняется.

### Объём реализации

Выпуск: параллельно.

**Реализует:**

- Job покрытия (`cargo llvm-cov`) со всеми сервисами; отчёт — артефакт; порог — после первого замера.
- Шаг `cargo semver-checks` против опубликованной версии каждого пакета.
- Job сборки и тестов на macOS (без сервисов).
- Job MSRV: тесты ядра на 1.99.

**Не входит:**

- Windows.

**Зависит от заявок:** нет.
