## 1. Предложение

### Цель изменения

Первый потребитель закреплён на компиляторе 1.96.1, а пакет `taskcraft` объявляет `rust-version = "1.99"`: cargo отказывается его собирать. Код ядра возможностей 1.97–1.99 не использует. Проверено 2026-10-30: на 1.96.1 с `rust-version = "1.96"` проходят все тесты ядра со всеми возможностями (`log`, `metrics`, `test-util`), собираются все примеры ядра и сборка без возможностей; ни одна зависимость ядра не требует компилятора новее.

### Инициатор

Внедрение у первого потребителя, замечание TC-1: выпуск ядра с `rust-version = "1.96"`, задание CI на 1.96.1 со сборкой и тестами, включая примеры и возможности; запись в `MIGRATION`. Пакеты `taskcraft-kafka` и `taskcraft-postgres` потребителю не нужны и не меняются.

### Затронутые компоненты

- [x] Пакет `taskcraft`: `rust-version`, версия
- [x] CI: задание на 1.96.1
- [x] `.clippy.toml`, README ядра, `MIGRATION.md`

### Приоритет

высокий (блокирует внедрение)

### Обратная совместимость

Да: снижение минимальной версии компилятора.

### Объём реализации

Выпуск: `taskcraft` 0.4.1.

**Реализует:**

- `taskcraft`: `rust-version = "1.96"`.
- CI: задание «MSRV core (1.96.1)» — тесты ядра со всеми возможностями, сборка примеров ядра и сборка без возможностей на 1.96.1.
- Clippy проверяет ядро по его минимальной версии.
- README ядра, `MIGRATION.md`, спецификация.

**Не входит:**

- `taskcraft-kafka`, `taskcraft-postgres`, внутренние пакеты: остаются на 1.99.

**Зависит от заявок:** нет (CI на обновлённых зависимостях — ветка `taskcraft/sebkd-65`).
