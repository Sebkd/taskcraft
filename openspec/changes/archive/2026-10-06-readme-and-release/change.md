## 1. Предложение

### Цель изменения

Первая версия готова: все заявки реализованы, примеры собраны. Лицо библиотеки отстало:

| Где | Что сейчас |
|-----|------------|
| README репозитория (он же страница `taskcraft` на crates.io) | «0.0.0 only reserves the crate name», раздел «What it will do», ни одного примера кода |
| Страница документации docs.rs (`lib.rs`) | «Work in progress» |
| README пакетов `taskcraft-kafka` и `taskcraft-postgres` | Короткие списки без кода |

Нужно:

1. **README, который показывает палитру возможностей на коде** — от минимальной очереди до сложных случаев:
   - повторы как данные и прерываемая пауза;
   - отказ при переполнении;
   - пулы ресурсов;
   - статус и отмена по идентификатору;
   - хук восстановления;
   - задача-автомат statecraft-fsm;
   - источник Kafka;
   - хранилище PostgreSQL с арендой;
   - наблюдаемость;
   - тестовый харнесс.
2. **Указать, что дизайн вдохновлён apalis**, — открыто и корректно, чтобы не было претензий. apalis распространяется под MIT; его код не использован (спецификация, раздел 1.1), заимствованы идеи.
3. **Подготовить выпуск 0.1.0 трёх пакетов** и опубликовать их на crates.io — по отдельной команде владельца проекта, после согласования и вливания README.

История изменений — спецификация и архив заявок; отдельный changelog не ведётся (решение владельца проекта).

### Объём реализации

**Реализует:**

- **README репозитория:**
  - Шапка: назначение в одной фразе, значки (CI, crates.io, docs.rs, лицензия, MSRV).
  - «Быстрый старт»: зависимость и минимальная очередь.
  - «Возможности» — по разделу на каждую с коротким компилируемым фрагментом. Фрагменты — выжимки из примеров каталога, со ссылкой на полный пример.
  - Таблица пакетов и возможностей сборки (`metrics`, `log`, `test-util`; TLS у хранилища).
  - Гарантии: at-least-once, идемпотентный приём, библиотека не паникует, журнал без аргументов задач.
  - Ссылки на каталог примеров и спецификацию; требования (Rust 1.99, edition 2024).
  - Благодарности: apalis и statecraft-fsm. Лицензия.
- **README пакетов** Kafka и хранилища: подключение, пример, настройки, гарантии.
- **Документация docs.rs:** вводная `lib.rs` трёх пакетов вместо «Work in progress».
- **Выпуск 0.1.0:**
  - версия workspace `0.1.0`;
  - зависимости пакетов на `taskcraft = "0.1.0"`;
  - снятие `publish = false`;
  - проверка `cargo publish --dry-run` всех трёх пакетов;
  - сама публикация — по команде владельца.

**Не входит:**

- Изменения поведения библиотеки.
- Перевод спецификации на английский.

**Зависит от заявок:** все заявки первой версии, включая `shutdown-report-counts`.
