## Чеклист верификации

### Основной сценарий

- [ ] Сообщения с ключами исполнены, смещение зафиксировано
- [ ] Граница фиксации на брокере (№23)

### Альтернативные сценарии

- [ ] Сообщение без ключа → сгенерированный идентификатор, WARN один раз (критерий заявки №2)
- [ ] Заголовок с зарегистрированным именем → метаданные (критерий заявки №3)
- [ ] Два процесса одной группы → каждая задача один раз (критерий заявки №5)

### Ошибочные сценарии

- [ ] Автофиксация в свойствах → выключена (критерий заявки №1)
- [ ] Брокер недоступен → ошибка источника (критерий заявки №4)
