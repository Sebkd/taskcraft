## Чеклист верификации

### Основной сценарий

- [ ] «Пусто» 1000 раз, затем задача → воркер жив, задача исполнена (спецификация №1)
- [ ] «Успех» → «Завершена», ack при «после завершения» выполнен после исхода и не раньше (№3, №39)
- [ ] «Закрыт» → «Дренаж», «Остановлен», журнал WARN с причиной, итог монитора с причиной (№2, часть журнала)

### Альтернативные сценарии

- [ ] Ошибки источника → «Перезапуск» с задержками 1, 2, 4 с, сброс после успеха; задачи не прерваны (№9, №10)
- [ ] Ошибка ack завершившейся задачи в «Ожидании» → «Перезапуск» (критерий заявки №2)

### Ошибочные сценарии

- [ ] Отравленное сообщение → хук, ack, следующая задача исполнена (№8)
- [ ] Ack не удался → исход прежний, «Перезапуск» (№25)
- [ ] Остановка: таймаут 10 с, задача на час → признак, прерывание, итог 0 / 1 / 1 (№21, часть задач в работе)

### Нефункциональные требования

- [ ] Записи журнала — `event`, `action`, `message` (2.9); спаны попыток уровня DEBUG (4.4.1)
