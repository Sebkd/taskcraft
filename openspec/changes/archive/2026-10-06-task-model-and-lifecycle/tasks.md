## Чеклист верификации

### Основной сценарий

- [ ] Метаданные задачи кодируются во внешнее представление и обратно → получается объект 2.7.2, значения совпадают с исходными (критерий заявки №4)
- [ ] Неизвестное читателю имя метаданных сохраняется при повторном кодировании (спецификация, критерий №29)

### Альтернативные сценарии

- [ ] В задачу дважды записано значение одного типа → остаётся второе (№2)

### Ошибочные сценарии

- [ ] Попытка перехода вне таблицы 2.4.1 → отклоняется, состояние не меняется (№1)
- [ ] Повтор имени или типа в реестре, регистрация `trace_parent` → ошибка конфигурации с сообщениями 2.10 (№3)
- [ ] Неразборное значение → ошибка, без значения по умолчанию (инвариант 1.3.11)

### Нефункциональные требования

- [ ] `Debug` метаданных не выводит значений (инвариант 1.3.18)
- [ ] Ядро не тянет зависимостей Kafka, СУБД, metrics (инвариант 1.3.14)
