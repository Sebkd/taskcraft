## Чеклист верификации

### Основной сценарий

- [ ] Лимит 2, «ждать», лимит ожидания 10, 4 долгие задачи → две в работе, две ждут, приём не ждёт исполнения (№13)

### Альтернативные сценарии

- [ ] Лимит 1, «отказать» → хук вызван, сообщение подтверждено, приём продолжается (№14)
- [ ] Пулы {A, B} и {B, A} → без взаимной блокировки (№16)

### Ошибочные сценарии

- [ ] Лимит ожидания исчерпан → источник не опрашивается; остановка видна сразу (№40)
- [ ] Перезапуск 60 с и ожидание слота → остановка прерывает оба сразу (№41)
- [ ] Неизвестный пул → «unknown pool» (критерий заявки №1)

### Нефункциональные требования

- [ ] После каждого исхода слот и разрешения пулов свободны (№15, инвариант 1.3.6)
