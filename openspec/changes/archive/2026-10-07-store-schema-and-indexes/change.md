## 1. Предложение

### Цель изменения

Три проблемы хранилища PostgreSQL, которые проявятся в эксплуатации.

1. **Нет версии схемы.** Таблицы создаются `CREATE TABLE IF NOT EXISTS`: первая же правка схемы в следующей версии не применится к существующим базам.
2. **Очистка по сроку хранения без индекса.** `DELETE` терминальных задач идёт каждый тик обслуживания (10 с) каждым процессом и проходит всю таблицу.
3. **Запрос захвата задачи** с условием «готова ИЛИ аренда истекла» может не использовать индекс и сортировать таблицу на каждый опрос.

### Инициатор

Код-ревью 0.1.0, бэклог код-ревью 0.1.0 (`docs/taskcraft-backlog_code-review-0.1.0.md`, локальный): BL-05, BL-06, BL-15.

### Затронутые компоненты

- [x] Пакет `taskcraft-postgres`: схема, обслуживание, запрос опроса

### Приоритет

высокий

### Обратная совместимость

Да: существующая схема 0.1.0 становится версией 1 и обновляется миграциями при старте.

### Объём реализации

Выпуск: до пилота.

**Реализует:**

- Таблица `taskcraft_schema` и упорядоченные миграции под advisory-блокировкой; схема 0.1.0 — версия 1.
- Отказ стартовать, если версия базы новее поддерживаемой.
- Частичный индекс по `updated_at` для терминальных задач; очистка раз в минуту порциями.
- Запрос захвата без `OR`: сначала готовые задачи, затем с истёкшей арендой; частичный индекс по `lease_until`; проверка `EXPLAIN` на 1 млн строк.

**Не входит:**

- Секционирование таблицы по времени.

**Зависит от заявок:** нет.
