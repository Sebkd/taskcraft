## 1. Предложение

### Цель изменения

При конкурентности больше 1 сообщения одного раздела обрабатываются параллельно, и порядок не сохраняется; фиксация по границе это учитывает. Ни README пакета, ни 2.6 этого не говорят — потребитель, привыкший к порядку Kafka, узнает в эксплуатации.

### Инициатор

Код-ревью 0.3.0, бэклог код-ревью 0.3.0 (`docs/taskcraft-backlog_code-review-0.3.0.md`, локальный): BL-39.
