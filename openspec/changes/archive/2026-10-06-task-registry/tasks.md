## Чеклист верификации

### Основной сценарий

- [ ] Две одновременные постановки с одним идентификатором → одна принята, другая «уже ведётся», обработчик один раз (№17)
- [ ] Статус задачи в работе → «В работе» с номером попытки; после завершения → «неизвестна» (№38)

### Альтернативные сценарии

- [ ] Отмена: обработчик проверяет признак → завершился сам; не проверяет → прерван по льготному времени (№19)
- [ ] Отмена задачи «В очереди» in-memory → убрана из источника, «отменена» (критерий заявки №1)

### Ошибочные сценарии

- [ ] Незарегистрированный тип метаданных → ошибка постановки (№28)
- [ ] Источник без постановки; постановка после остановки → ошибки 2.11.2 (№42)

### Нефункциональные требования

- [ ] Реестр пуст после завершения всех задач (№18, инвариант 1.3.9)
