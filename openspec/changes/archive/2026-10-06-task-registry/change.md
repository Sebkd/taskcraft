## 1. Предложение

### Цель изменения

Сделать задачу адресуемой по идентификатору: запрос статуса, отмена на ходу, а повторная постановка с тем же идентификатором — не вторая задача, а ответ «уже ведётся». Первый потребитель держит для этого собственный реестр и вручную снимает записи на каждом терминальном пути; пропущенный путь — утечка, видимая только под нагрузкой.

Отмена кооперативная: обработчик видит признак отмены, по истечении льготного времени попытка прерывается принудительно.

### Инициатор

Разработка первой версии taskcraft (ветка `taskcraft/sebkd-1`). Требования первого потребителя — спецификация, раздел 1.1.

### Затронутые компоненты
