## Чеклист верификации

### Основной сценарий

- [ ] Исходы записаны в хранилище; статус виден другим процессам
- [ ] Два процесса — задачу получает один (критерий заявки №1)

### Альтернативные сценарии

- [ ] Рестарт без аренды возвращает свои задачи (№30 б, №43)
- [ ] Подхват по истёкшей аренде (№31)
- [ ] Отмена задачи другого процесса (критерий заявки №4)

### Ошибочные сценарии

- [ ] Идентификатор процесса занят (№44)
- [ ] Потеря аренды — отмена без записи (№45)

### Нефункциональные требования

- [ ] Срок хранения (критерии заявки №2, №3)
