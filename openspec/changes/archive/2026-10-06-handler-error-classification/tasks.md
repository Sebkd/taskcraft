## Чеклист верификации

### Основной сценарий

- [ ] К обработчику применён стандартный слой tower → работает без адаптеров (критерий заявки №2)

### Альтернативные сценарии

- [ ] «Прервать», в том числе упакованная ошибка общего типа → исход `Abort`, классификация не теряется (спецификация №5, в части классификации)

### Ошибочные сценарии

- [ ] Обработчик с неверной сигнатурой → ошибка компиляции (№1)
- [ ] Паника обработчика → исход `Panic`, не `Retry` (спецификация №6, в части классификации)
- [ ] Неразборные обязательные метаданные → обработчик не вызван, `Abort` с причиной, значения по умолчанию нет (спецификация №27)

### Нефункциональные требования

- [ ] Без `unsafe`; новых зависимостей, кроме `tower`, нет
